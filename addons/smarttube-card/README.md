# SmartTube Link

A lightweight launcher module card that acts as a quick shortcut to launch the official SmartTube app if installed on the TV.

This add-on contains **no code, no binaries, and no bundled APKs** from SmartTube. It dynamically queries Android's `PackageManager` at runtime for an installed Leanback or standard launcher activity belonging to SmartTube (such as SmartTube or SmartTube Next by yuliskov).

If SmartTube is not installed, it displays a friendly on-screen message advising the TV owner to install the official release.

## Permissions

None. This app requires no permissions and has no network access.
